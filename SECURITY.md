# Security Policy

## Supported Versions

We provide security updates for the latest development release:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The StayNest team and community take security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings.

### How to Report

If you discover a security vulnerability within StayNest, please report it privately:

1. **Do not** disclose the vulnerability publicly in an open GitHub issue or public repository discussion.
2. Send an email with details and reproduction steps to **security@staynest.dev**.
3. Include the following details where possible:
   - A detailed description of the vulnerability and its potential impact
   - Step-by-step reproduction instructions or proof-of-concept script
   - Affected endpoints, parameters, or components
   - Any suggested mitigations or patches

### Response Timeline

- **Initial Response:** You will receive an acknowledgment within 48 hours of reporting.
- **Assessment:** We will confirm the vulnerability and determine its severity within 5 business days.
- **Fix & Disclosure:** We will work on a patch and coordinate a disclosure timeline once the fix is deployed.

Thank you for helping keep StayNest and its community safe!
